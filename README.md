# NETFLIX_SQL_DA_PROJECT-
This project focuses on analyzing Netflix’s dataset to uncover insights about the platform’s content distribution, genres, countries, ratings, and trends over time. Using SQL, various analytical queries are performed to answer real-world business questions
This project is based on Netflix Data Analysis using SQL, where I explored and analyzed Netflix’s dataset to find useful insights about movies and TV shows. Using SQL queries, I analyzed various aspects such as the total number of movies vs TV shows, the most common ratings, the countries with the most content, and the trends in content added over the years. I also identified the longest movie or show duration and filtered titles by specific directors. The project demonstrates how SQL can be used for real-world data analysis tasks like filtering, grouping, and aggregating data to uncover meaningful insights. The dataset used was the Netflix Titles Dataset from Kaggle, and all analysis was done using postgresql.
